# Research project framing

Use `cairn project create` to propose the question, objective, and constraints. Approve
and apply the result before importing project receipts. Fill these additional sections
through `cairn edit`; do not overwrite managed records with a template.

- Question and claimed contribution
- Closest literature, with source IDs and precise locators
- Assumptions and identification strategy
- Conjectures versus proven results (separate assertion kinds)
- Data and experiment manifests in the project repository
- Failed approaches and negative results, attributed to evidence
- Decisions proposed versus explicitly adopted by the owner
- Unresolved issues and the next test
- Repository alias, commit, working-tree fingerprint, run IDs

No data, checkpoints, or manuscripts are copied into the wiki. Unknown values remain
unknown. `cairn context` includes only the named project's authorized material.

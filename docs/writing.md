# Reading and writing knowledge

A paper has an evolving note with a stable identity, source versions, coverage, checkpoints
and unresolved questions. A topic is a learning notebook, not just a list of papers. Start
with intuition, prerequisites, mechanisms, equations, examples and comparisons; preserve
personal observations separately. Research questions are concept records with kind=question.
All six record types remain available, and ordinary saves never adopt or verify decisions.

Finch supplies reading method; Quill helps develop the learning explanation. Their own skills
stay independent. Cairn's contract tells the connected agent to retrieve existing knowledge,
save checkpoints, distinguish source-stated connections from inference, and resume pending
work. Templates are in [templates](../templates/). Save JSON schemas are in [schemas](../schemas/).

Use [installation](installation.md) for commands, [recovery](recovery.md) for conflicts and
undo, and [HTML companions](notebook-html.md) for visual resources and feedback.
The prior writing workflow remains in [legacy/writing-v3.md](legacy/writing-v3.md).
